# Исправление системы продолжения игры

## Проблема
После обновления страницы игра не предлагала продолжить игру со второго уровня, хотя система сохранения была реализована.

## Диагностика
Добавлены отладочные сообщения для выявления проблемы:
- В `GameStateManager` - для отслеживания сохранения/загрузки состояния
- В `StartMenu` - для проверки наличия сохраненной игры
- В `Game` - для отслеживания сохранения состояния игры

## Решение

### 1. Улучшенная система кнопок
Теперь система показывает:
- **"Продолжить игру (Ур. X)"** - если есть сохраненная игра
- **"Новая игра"** - если есть сохраненная игра (вместо "Начать играть")
- **"Начать играть"** - если нет сохраненной игры

### 2. Исправления в коде

**StartMenu.gd:**
- Добавлена функция `_setup_game_buttons()` для настройки кнопок
- Функция `_rename_start_button_to_new_game()` переименовывает кнопку при наличии сохраненной игры
- Функция `_restore_start_button()` восстанавливает стандартный текст
- Улучшена функция `_on_start_button_pressed()` для правильной обработки новой игры

**GameState.gd:**
- Добавлены отладочные сообщения для отслеживания состояния
- Улучшена функция `_load()` с подробным логированием

**Game.gd:**
- Добавлены отладочные сообщения в `_save_current_game_state()`

### 3. Новые переводы
Добавлены переводы для кнопки "Новая игра":
- Русский: "Новая игра"
- Английский: "New Game"

## Как это работает теперь

1. **При загрузке StartMenu:**
   - Проверяется наличие сохраненной игры
   - Если есть - показывается кнопка "Продолжить игру" + "Новая игра"
   - Если нет - показывается стандартная кнопка "Начать играть"

2. **При нажатии "Продолжить игру":**
   - Загружается сохраненный уровень с восстановленным счетом

3. **При нажатии "Новая игра":**
   - Завершается текущая игра
   - Начинается новая игра с первого уровня

## Отладочные сообщения
Все функции теперь выводят подробные сообщения в консоль для диагностики:
- Сохранение/загрузка состояния игры
- Проверка наличия сохраненной игры
- Создание кнопок интерфейса
- Переходы между уровнями
